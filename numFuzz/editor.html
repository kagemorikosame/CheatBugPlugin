置き換えルール（このサイトのみ）

値：JS・JSON と Unity の C# コード内で「元の値」と一致する数値を「新しい値」にします。
キー：JSON のキー名や JS の name: 100 / name = 100 の値を「新しい値」にします。
C#：Unity の C# メソッド内の特定の定数を「新しい値」にします（下の検出値「C# (Unity)」から追加）。
ルールに当てはまった値はランダム書き換えより優先されます。C#整数 は値ルールを C# コード内の整数にも適用します。
Unity では、名前の分かるゲームの C# メソッド（Assembly-CSharp）以外（エンジン・ライブラリ）は書き換えません。
変更はゲームページをリロードすると反映されます。

有効 種類 元の値 / キー名 新しい値 C#整数
ルールはまだありません。
実行中の変数（Unity・プレイ中に直接変更）

プレイ中のゲームのメモリから C# の変数（クラスのフィールド）を読み取り、その場で書き換えます。リロードは不要です。
名前はゲームのコードと同じです（例: playerStatus.clearCount は playerStatus.GetClearCount() が返す値）。 固定 にすると、ゲームが値を変えても書き戻し続けます。
ゲームがセーブすると書き換えた値も保存されます。ゲームのページを再読み込みすると固定は解除されます。

検出値（最後の読み込み時・書き換え前の値）

NumFuzz が有効なサイトで読み込まれた JS・JSON の数値と、Unity のゲームの C# メソッド内の定数です。値・キー名・メソッド名で検索し、「＋」でルールに追加できます。


「意味（推定）」は wasm の命令から推定した C# 側の使われ方です（this.money = ● はフィールドへの代入、 PlayerPrefs.GetInt("Money", ▶defaultValue) は引数、ローカル変数（≒ Random.Range()） <= ● は if 文などの比較）。 コルーチンの内部状態やオブジェクトの参照など、変えるとゲームが壊れる値は表示しません。
おすすめ以外（意味が「（不明）」「ローカル変数」のもの）はループの回数などの可能性があり、変えるとゲームが止まることがあります。
