# ChaosMode

## 概要

- Webサイトの見た目・動作をランダムに書き換えて「バグったような状態」にするブラウザ拡張機能
- Firefox用WebExtension（manifest_version 2）
- 対象タブに対してのみ動作し、ページのリロードで元の状態に戻る
- カオスレベル（1〜5）で崩壊の激しさを調整可能
- 主な機能
  - CSS書き換え（色・サイズ・変形などを不規則に変化）
  - テキストグリッチ（指定したグリッチワードをランダムに挿入）
  - 要素シャッフル（DOM要素の並び順をかき混ぜる）
  - 画像のランダム差し替え
  - ブラー効果（負荷が高め）
  - JS定数バグ（速度・倍率などの数値を破壊）
  - 音声のピッチ・速度をランダム化
- 設定内容は拡張機能のstorageに保存され、ポップアップを開き直しても前回の値を維持

## 導入方法

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」をクリック
3. プライベートウィンドウで動かす場合`about:addons`へアクセスし`ChaosMode`を選択後「プライベートウィンドウでの実行」を許可するに選択
4. `htmlBug` フォルダ内の `manifest.json` を選択
5. ツールバーにChaosModeのアイコンが追加されることを確認
6. カオスを起こしたいサイトを開き、アイコンをクリックしてポップアップを表示
7. カオスレベルとオプションを設定
8. 「⚡ チートバグ発動！」ボタンをクリックして適用
9. 元に戻したい場合は「↺ リセット」ボタンをクリック、またはページをリロード

※ 一時的な読み込みのため、Firefoxを再起動すると拡張機能は解除される
